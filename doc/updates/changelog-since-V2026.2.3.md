# V2026.2.3 以来的更新日志

本文整理 `V2026.2.3`（`177137a`）之后至 `f189507` 的已实现变更，覆盖截至 2026-09-19 的 67 个提交，包含合并提交。同一功能的连续实现与修正合并描述，不把一次功能反复计为多个新增项。

**状态：待发布，下一版本号尚未指定。** 当前编译版本仍为 `2026.2.3`，按维护者安排在审计通过后手动迭代。初审发现的图片消息分支崩溃已在 `4fea66f` 修复并验证，详见 [发布前 QA 审计](../release-qa-audit-since-V2026.2.3.md)；本更新日志不代表整体发布已获放行。2026-09-19 复审新发现导入单条消息超过四张图片后无法保留全部附件并保存正文编辑，尚未修复，详见审计报告。

## 新增

### 单聊与群聊图片消息

- 单聊、群聊可以发送图片与图文消息，也支持正文为空的纯图片消息。
- 输入区增加图片选择与预览；用户消息编辑支持新增、移除、排序和保留附件。角色消息可保留、移除和排序已有附件，暂不开放添加图片入口。
- 每条新发送或编辑的消息最多四张图片；单次模型请求另有图片数量与总大小限制，当前最多十二张图片。
- 增加图片查看器，支持缩放、双击、左右切换、缩略图导航与保存图片。
- 新增图片发送策略：自动、原图、自定义。自动模式按最长边 1536 px、每图 2 MiB 处理；自定义可设置大小及宽高上限。原图模式不隐式缩放或转码，但仍受客户端资源上限约束。
- 附件在发送或保存编辑时确定最终文件；已有附件继续使用保存的字节，不因后续修改压缩设置而重新处理。

主要提交：`12406c2`、`cf57bb5`、`407a370`、`4ca827d`、`8c679bb`。

### 多模态模型适配与预算

- 为 OpenAI-compatible、Gemini、Anthropic 三种协议接入图片请求编码。
- 模型配置增加图片输入能力设置，支持自动判断及手动指定。
- 增加图片 token 估算策略，图片成本参与上下文和摘要预算。
- 在 Prompt 检查器中展示图片相关信息及被省略的原因。
- 图片数量、体积、模型能力和上下文限制在发送链路中统一检查；不支持图片或校验失败时提供对应提示。

主要提交：`12406c2`、`cf57bb5`、`50b456e`。

### 聊天图片归档

- 单聊 JSONL 归档可携带图片，支持 RPClient 导出后再导入恢复附件。
- 通过 `extra.rpclient` 的版本化扩展保存图片数据和元信息，保留文字聊天归档兼容路径。
- 可导入 SillyTavern 的图片消息，识别新版 `media` 以及旧版 `image`、`image_swipes` 字段，也支持角色消息中的图片。
- 遇到外部图片引用时，可通过用户选择的资源目录匹配文件；缺失图片会统计并跳过，不自动下载远端引用。
- 增加 GZIP 压缩，仅在至少节省约 5% 时使用；通过 SHA-256 去重，后续重复图片引用归档中此前出现的相同资源。
- 导入检查图片 hash、解压后大小和资源限制；取消或失败时清理暂存并回滚，减少大归档对内存的占用。

兼容说明：SillyTavern 可忽略 RPClient 自定义扩展，因此“文字格式兼容”不等于其能够显示 RPClient 导出的内嵌图片。

主要提交：`bea72e0`、`c745b0b`。

### Token 用量统计

- 新增 Token 用量页，展示输入、输出、总量与成功请求次数。
- 支持时间范围筛选、柱状或趋势图、模型与 API 主机维度汇总，以及最近请求明细。
- 支持清除统计记录。
- 模型配置增加“使用服务端上报用量”策略；未取得可用服务端用量时按相应本地估算路径统计。
- 支持选择本地 Token 预估器类型。
- 新建 DeepSeek 预设默认启用服务端用量；不强制修改已有配置。
- 用量统计保存必要的计数与模型、主机信息，不在统计表中保存 API Key 或请求、响应正文。

主要提交：`a496bdf`、`885df1b`、`91d2d29`、`35ac0f0`、`7825d9e`。

### 个性化、模型配置与语言

- 新增主题配色选择：跟随系统、浅色、深色。
- 模型配置列表支持克隆已有配置，保留参数与请求扩展，便于调整新的配置副本。
- 新增葡萄牙语（巴西）、意大利语、越南语、印度尼西亚语翻译，并补齐已有语言的新功能文案。
- 支持用户安装的系统级 CA 证书，方便连接使用自定义证书链的服务。

主要提交：`edff421`、`af40fa9`、`87f634c`、`fecc2f1`、`83a9677`。

## 优化

### 大量历史消息与上下文构建

- 单聊和群聊改进分页加载，减少一次性读取全部消息的开销。
- 使用稳定的消息键与分页窗口，改善长会话的滚动和加载行为。
- 增加“最多参与 Prompt 的历史消息数”设置，默认 500，设为 0 表示不限；仅限制请求上下文选取，不删除本地历史。
- 优化历史消息查询、Prompt 拼装及 token 计算，降低长对话重复扫描成本。
- 优化摘要候选范围和可容纳前缀的查找，减少重复构建与估算。
- Bitmap 读取增加采样处理，降低大图片展示时的解码开销。

## 升级后的行为变化

- 主数据库由 schema 3 升级至 schema 4，增加图片关系、用量记录与模型能力设置；保留旧 schema 的迁移链。
- 旧 Gemini、Anthropic 配置保留服务端用量行为；旧 OpenAI-compatible 配置默认不额外开启服务端用量请求选项，避免改变兼容端点的请求要求。
- 长聊天默认最多选取 500 条历史消息参与 Prompt，需要更大范围的用户可以调整该设置；原有聊天记录不会因此删除。
- 图片压缩设置只影响之后新增或重新保存的附件，不改变已保存附件；“保存原图”取得的是应用当前保存的图片字节，自动压缩后不会额外保留选择前的大文件副本。
- 系统要求维持 minSdk 26、targetSdk 36，没有在本轮提高最低 Android 版本。
